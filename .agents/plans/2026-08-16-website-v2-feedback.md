- Every checkbox in `~/feedback.md` is resolved or explicitly deferred with a stated reason; no "liked as-is" area is regressed (Projects layout/search/ombre, About timeline tone, Footer copy, `Recent Changes` 4-panel grid, large Realm bento card).

## Recommended Approach

Work is five sequenced slices that keep diffs small and shippable. Order matters: type-scale first (so later slices don't have to guess sizes), then global chrome (header/footer + capitalization), then homepage (hero + featured + recent changes), then About/Resume, then Connect + mobile polish. Each slice ends with a build check at its breakpoint.

1. **Establish a systematic type scale (tokens + globals).**
   - Add a `typography` scale to `packages/design-tokens/tokens.json` (e.g., `font.size{ xs, sm, base, lg, xl, h2, h1 }` or a `type` namespace), run `npm run build:tokens`, and have `src/styles/globals.css` + component CSS consume it for: `s-head h2`, `.section h2`, `.bento h3` (both tiers), `.desc`, `.log-card .t/.d`, `.k-label/.eyebrow`, `.out-k/.out-v`, `.t-role/.t-desc`, `.foot`, `.nav-*`, `.card h4`, Contact card type (`pgp-desc`, `lm`, `badge`, `fp`), etc. Global mobile base bump via a slightly larger `html { font-size }` or token-driven `body` size plus the media queries.
   - This is the only slice that edits `packages/design-tokens/`.

2. **Header/Footer + capitalization (Nav/Footer/config).**
   - Add/swap logo asset (`favicon.svg` as placeholder or new `logo.svg` in `website-v2/public/`), edit `Nav.tsx` to render `<img>` before `siteConfig.wordmark` and adjust `Nav.css` (`.wordmark` gap, image size). Bump `.wordmark`, `.nav-links`, `.nav-side`, `.foot` via the new type vars. Normalize section header capitalization in data/JSX: `Featured work → Featured Work`, `Recent changes → Recent Changes` (and any lowercase headers in data), and enforce a rule for future headers.

3. **Homepage: hero image + featured bento + recent changes.**
   - Re-introduce the two-column hero grid (`Home.css`), add `hero-photo` with `img` (data fix: expose a `homeHeroImage` path in `data/home.ts` or just reference `/assets/about.jpg`), ensure graceful mobile stack. Promote `FeaturedBento` to team-tinted cards (add `team: 'red-team'|'blue-team'` to `homeBento`, apply `is-red`/`is-blue` + top-signal gradient). Unify title sizes via CSS. Fill Realm extra space with a metadata row (reuse `foot` plus a `stats` line/star count) — no `desc` padding. Bump `Recent Changes` card titles/body and `.s-head` per type scale and verify line spacing.

4. **About + Resume.**
   - `About.css`: Enlarge `.ah1`/`.lead`, enlarge and widen image column (e.g., hero person column `380px` or `minmax(0,1fr) minmax(280px, 0.9fr)`), raise `.ph` height (280–320), align `.outside max-width` with `.timeline (860px)`, bump `.out-k/.out-v` and `.k-label`, add `.out-v ul { padding-left: 18–20px }` with a mobile inset tweak. `ResumePage.tsx`: add a class (e.g., `resume-viewer`) + CSS rule `@media (prefers-color-scheme: dark) { .resume-viewer { background: #000 } }` on the container only (paper stays `#fff`), plus optional inline `<style>` if not moving to a CSS file.

5. **Connect + mobile sweep.**
   - `ContactPage.tsx`: reflow `<h1>` into three `<span>` lines (or `br` placement) so it renders as `Come` / `Find me` / `Elsewhere` at all widths. `ContactSide.tsx`: restructure each section as `<h3 header>` + `<div class="card">` (**Follow the Work**, **Résumé**, **Encrypted Questions**) preserving current links/badges. Bump box content type (`pgp-desc`, `.fp`, `.lm`, etc.) via type vars, apply email obfuscation (display `joe [@] joeabate.me`, `mailto:` assembled or verified at runtime). Final responsive pass: 900/520 breakpoints for hero, bento, about hero, contact layout, bullet inset, and Projects (unchanged) — confirm no new horizontal scroll, focus rings visible.

## Risks / Rollback

- **Width/layout reflow:** increasing base type and enlarging hero/outside containers can overflow at 900/520 or push Projects' 2-col grid. Mitigate by keeping the `1120px` `contentMax` and testing each unit at 1280/900/520; the About `outside`/`timeline` alignment is specifically `720→860` only, not broader container growth.
- **Token churn:** editing `packages/design-tokens` requires consumers to rebuild; a missing `npm run build:tokens` leaves stale `dist/*`. Mitigate: run the token build as the first command in #1 and commit `dist/*` with the token bump (already tracked).
- **Missing image asset:** if no personal/lab photo is supplied, the hero will ship with a blank or 404. Mitigate: require the asset at `public/assets/about.jpg` (and optional `lab.jpg`) before closing #3; ship a CSS placeholder reserving the space so layout is correct even before the real file lands.
- **Dash sweep overreach:** replacing `—` in prose where the pair ` — ` is grammatical. Mitigate: keep grammatical pairs only if explicitly decided; default to `:` or `//` and grep `—|–` → zero hits (except code/comments).
- **Dark-mode spill:** resume viewer media query leaking to the PDF paper. Keep the selector on the **container** (`resume-viewer`) only, not the paper/inner `#fff` card; test dark-mode emulation explicitly.
- **Rollback:** each unit is revertible by checking out its files; slice #1 is the only cross-cutting one — if type bumps break balance, revert `tokens.json` + `dist/*` and keep per-file `px` on the specific overflow component rather than rolling the whole feedback.
